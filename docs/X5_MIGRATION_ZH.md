# X5loco v8 → MUJICA 迁移说明

日期：2026-09-16。参考本机 `X5loco` 的实际 v8 源码及其继承的 v7/v6/X5 配置。
本次只做源码适配，没有运行测试、编译、配置检查、仿真或训练。

## 1. 整体数据链

```text
X5 URDF / 网格 → 固定附件合并 → Isaac Lab articulation / 接触传感器
    → 按名称重排状态 → 6 帧 MUJICA 观测 → GRU 估计器 → 共享 actor
    → 腿位置目标 + 轮速度目标 → 显式 PD / 停车 PI → 静态力矩限幅
    → 物理步 → v8 奖励与真实终态 → 普通 PPO
```

S1 按出生地形给定技能，S2 训练选择器。三个任务继续是平地及坡道、离散障碍、楼梯。
没有替换为 X5loco 的网络、观测历史或训练算法，也没有移植旧高台／恢复任务。

## 2. 机器人与控制接口

资源位于 `resources/robots/x5/`，训练时不需要安装或引用服务器上的 X5loco。
URDF 的 6 个固定附件合并到其父体，保留 17 个动态刚体；轮关节是连续关节，不参与角度限位惩罚。

策略动作／关节观测顺序：

```text
0..11: RF_HAA RF_HFE RF_KFE  LF_HAA LF_HFE LF_KFE
       RH_HAA RH_HFE RH_KFE  LH_HAA LH_HFE LH_KFE
12..15: RF_WHEEL LF_WHEEL RH_WHEEL LH_WHEEL
```

轮体、接触、轮间距和轮离地高度均使用 RF/LF/RH/LH 顺序。与 PhysX 内部顺序按名称映射。
轮间距和轮离地高度使用轮轴所在的 link 原点；轮轴倾斜时按轮圆盘的竖直投影修正半径。

| 参数 | X5 配置 |
|---|---|
| 默认腿角 HAA/HFE/KFE | `0 / 0.80 / -1.50 rad` |
| 参考机身高度 / 出生高度 | `0.567 / 0.587 m` |
| 轮半径 | `0.1005 m` |
| 腿位置目标 | 默认角度 + `0.2 × action` + 电机零位扰动，再限幅 |
| 腿目标限位 | 右 HAA `[-0.79,0.64]`，左 `[-0.64,0.79]`，HFE `[-1.60,2.39]`，KFE `[-2.32,-0.52]` |
| 轮速度目标 | `action / 0.1005`，限幅 `±24 rad/s` |
| 腿 PD | `Kp=800, Kd=20` |
| 运动中的轮速度 P | `Kd=3` |
| 力矩上限 HAA/HFE/KFE/轮 | `300 / 250 / 250 / 30 Nm` |
| 关节速度上限 HAA/HFE/KFE/轮 | `6 / 6 / 8 / 30 rad/s` |
| 物理 / 策略周期 | `2.5 / 20 ms`，decimation=8 |
| 碰撞 | 开启自碰撞；接触偏移 2 mm；机身接触超过 10 N 终止 |

关节角度软限位奖励使用 URDF 限位的 0.9 倍区间，和上表的动作目标限位是两组不同约束。
默认关闭 Go2W 的未校准电机包络，X5 使用自身 URDF 静态限幅。
这仍是仿真控制参数，尚没有本项目的物理运行或真机验收结果。

### 停车 PI

同时满足平移指令 <0.02 m/s、偏航指令 <0.04 rad/s 才进入停车；
达到 0.03 m/s 或 0.05 rad/s 即退出。
等待 0.2 s 后用 0.2 s 平滑将轮速目标降为零；确认接触后才积分。
Ki=3，积分限幅 ±12 Nm，总轮力矩限幅 ±30 Nm，含抗积分饱和。
离地、重新运动或环境重置会清空对应积分，按 2.5 ms 物理步更新。
停车目标惩罚读取覆盖为零之前的策略请求，避免控制器替策略掩盖错误指令。

### MUJICA 观测

| 部分 | X5 维度 |
|---|---|
| 单帧：角速度、重力、指令、关节角误差、关节速度、上次动作、技能 | 58 |
| actor：6 帧，最新在前 | 348 |
| critic：58 + 基座速度3 + 接触17 + 轮离地4 + 高度187 | 269 |
| 选择器历史：每帧去掉技能编号 | 342 |

连续轮角在观测副本中置零，轮速度保留。actor 不直接读取地形扫描。
runner 的接触／轮离地估计监督标签随碰撞维度改变，S2 critic 同步为 269 维。
X5 和 Go2W 权重不可混用，X5loco 权重也不具备这个 MUJICA 网络接口。

## 3. 三技能共用的 v8 奖励

`x5_config.py` 定义权重，`x5_parameters.py` 定义姿态容差，
`x5_state.py` 计算共享地形／动作状态，`x5_task.py` 连接到环境。
下表权重在求和时统一乘策略 dt=0.02；不把负总奖励截成零。

| 奖励／代价 | 权重 |
|---|---:|
| 平面速度跟踪 `tracking_lin_vel` | +2.0 |
| 偏航跟踪 `tracking_ang_vel` | +1.0 |
| 有方向的侧移进展 `lateral_progress` | +0.75 |
| 完成有效机动抬腿 `maneuver_completed_step` | +0.30 |
| 关节姿态容差外误差 `joint_pose_corridor` | -0.15 |
| 轮轴相对机身位置 `wheel_position_corridor` | -0.25 |
| 轴距缩短 `wheelbase_corridor` | -0.15 |
| 轮距缩窄 `track_width_corridor` | -0.15 |
| 局部机身高度 `height_corridor` | -0.35 |
| 地形允许范围外的机身倾斜 `terrain_roll_pitch_l2` | -1.0 |
| 停车轮速 `stop_wheel_speed_l2` | -0.10 |
| 停车策略轮速请求 `stop_wheel_target_l2` | -0.05 |
| 机身竖直速度 `lin_vel_z` | -2.0 → 0 |
| 机身横滚／俯仰角速度 `ang_vel_xy` | -0.05 |
| 关节机械功率 `joint_power` | -2e-5 |
| 动作一阶差分 `action_rate` | -0.01 |
| 动作二阶差分 `action_smoothness` | -0.01 |
| 大腿／小腿非期望接触 `undesired_contacts` | -1.0 |
| 腿关节软限位越界 `joint_pos_limits` | -2.0 |
| 腿关节加速度 `leg_joint_acc_l2` | -1e-7 |
| 轮关节加速度 `wheel_joint_acc_l2` | -2e-8 |
| 腿关节力矩 `leg_joint_torques_l2` | -1e-5 |
| 轮关节力矩 `wheel_joint_torques_l2` | -4e-5 |

速度跟踪核为 `exp(-error² / 0.4²)`，平面误差为 XY 平方和。
关节加速度使用 Isaac Lab 的物理步加速度，力矩使用 articulation 的 applied torque。
竖直速度权重在第 0～1500 个 learner iteration 线性降至 0；续训沿用保存的迭代数。
这里保留 MUJICA 每轮 48 步，因此衰减对应的物理时长与 X5loco 默认每轮 24 步不同。

### 如何让轮腿协同

1. 对 17×11 局部高度点拟合平面，再用残差和相邻高度跳变区分平地、坡道与粗糙地形。
   只看坡度容易把楼梯误当坡道，残差用于保留台阶边缘的信息。
2. 平地直行保持较紧的姿态；停车后逐渐收紧。侧移和转向时立即增加活动空间，
   指令结束后以 0.5 s 时间常数恢复。局部非平地进一步增加姿态和高度容差。
3. 姿态、轴距、轮距约束仍保留非零代价，抬轮不能关闭几何约束。
   允许平地 3°、粗糙地形 15° 的机身倾斜；坡道容许坡度+5°，最大 30°。
4. 有效抬腿事件须从确认支撑到真实离地再落地，飞行时间 0.10～0.70 s、离地至少 2.5 cm，
   落地时至少两轮得到支撑，并与指令方向上的净运动一致。每次落地只结算一次。

**v8 的完成抬腿奖励专门辅助侧移／转向。** 纯前向上楼没有额外的抬腿事件奖励；
前向越障仍靠速度跟踪和放宽后的姿态代价学习。没有增加固定步频或对角步态模板。
S2 始终只使用 +2.0 平面速度跟踪和 +1.0 偏航跟踪，保留 MUJICA 两阶段设计。

## 4. 参考范围及有意保留的差异

- 保留 MUJICA 的网络、观测归一化／噪声、PPO、三任务地形、地形课程和失败规则。
- 指令新增 v8 的停车10%、纯前后15%、纯侧移25%、纯转向10%；其余40%按三轴均匀采样。
  前后／混合指令 8～10 s，纯转向4～6 s，停车3～5 s。没有完整复制 v7 的边界指令采样。
- 当前速度范围固定为前后 ±0.5 m/s、侧向 ±0.2 m/s、偏航 ±0.5 rad/s；
  没有移植 v8 每轴 EMA 升降速课程，后续可在各技能稳定后单独引入。
- 参考 v8 缩小质量、COM、PD、摩擦、零位和出生姿态扰动，关闭旧 Go2W 延迟与外力脉冲。
  推扰采用每15 s的小幅速度增量；与 v8 每环境10～15 s定时器不同。
- 地形信息使用 MUJICA 的高度场采样，并增加与 v8 小扫描器同尺寸的 0.4×0.3 m 网格；
  不新增 RayCaster。台阶边缘由现有保守高度采样近似，和 v8 三角网格射线命中不完全等价。
- 接触传感器每物理步更新，保存3帧历史供非期望接触奖励使用。
- 导出记录新的关节顺序、269维 critic 对应网络、8步 decimation、目标限幅和停车 PI 参数。
  现有 Go2W MuJoCo PD 脚本不能等价执行 X5 控制，因此主动拒绝 X5 元数据。

S1 正式命令见[项目首页](../README.md)。如需要，下面是留给你执行的检查入口，本次没有执行：

```bash
python -m mujica.isaaclab.sim_smoke --robot x5 --num-envs 9 --steps 350 --terrain plane --headless
python -m mujica.isaaclab.sim_smoke --robot x5 --num-envs 9 --steps 350 --terrain trimesh --headless
```

日志保留 `task/flat_slope`、`task/discrete`、`task/stairs` 分组的跟踪、失败率和分项回报。

这些日志用于排查行为；源码移植本身不能证明机器人已学会三种运动。
